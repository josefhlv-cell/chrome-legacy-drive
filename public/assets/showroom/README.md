# Static showroom template — READ ONLY

These files define the single, permanent virtual showroom. They must never be
regenerated by AI or by a script.

| File | Purpose |
| --- | --- |
| `master_showroom_background.webp` | The one and only background (1920×1080 reference copy of the immutable storage master). |
| `camera.json` | Locked camera: height, pitch/yaw/roll, FOV, focal length, horizon. |
| `lighting.json` | Lighting signature used for colour matching and anti-halo cleanup. |
| `ground_plane.json` | Asphalt plane, tyre contact line, shadow direction, vehicle anchor. |
| `placement_rules.json` | Global placement rules, per-class profiles, validation thresholds. |
| `vehicle_masks/` | Cached vehicle cut-out masks (`<imageId>.png`), written by the pipeline only. |

The compositing pipeline mirrors these values in
`supabase/functions/_shared/showroomTemplate.ts` (the edge runtime cannot read
`/public`). If a value ever changes here, bump the version string in both places
and regenerate every composite explicitly from the admin Showroom tab.
