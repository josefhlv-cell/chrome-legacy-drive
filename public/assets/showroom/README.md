# Static showroom template — READ ONLY

These files define the single CHDP indoor showroom. They must never be
regenerated by AI. The photograph is the perspective reference.

| File | Purpose |
| --- | --- |
| `master_showroom_background.jpg` | The one plate, native 1500×846. Never stretch, crop the logo, or crop the floor circle. |
| `master_showroom_background.webp` | Same plate, reference copy. |
| `camera.json` | Locked camera. Rear wall is 6.60 m × 3.00 m. |
| `lighting.json` | Ceiling spots and floor reflection, for integration only. |
| `ground_plane.json` | Concrete plane, tyre line y=768, display circle. |
| `placement_rules.json` | Per-class scale. A 3/4 pickup is 70% of frame width. |
| `vehicle_masks/` | Cached cut-out masks, written by the pipeline only. |

The compositing pipeline mirrors these values in
`supabase/functions/_shared/showroomTemplate.ts`. The edge runtime fetches the
JPG from this folder. If a value changes, bump the version in both places.
Older composites then drop off the public site until Showroom is run again.
