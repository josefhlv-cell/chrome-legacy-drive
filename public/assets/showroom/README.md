# Static showroom template — READ ONLY

These files define the single CHDP indoor showroom. They must never be
regenerated by AI. The photograph is the perspective reference.

| File | Purpose |
| --- | --- |
| `src/assets/chdp-showroom-master.jpeg.asset.json` | The only user-approved unchanged plate, native 1920×1082, served through Lovable Assets. Never stretch or crop. |
| `camera.json` | Locked camera. Rear wall is 6.60 m × 3.00 m. |
| `lighting.json` | Ceiling spots and floor reflection, for integration only. |
| `ground_plane.json` | Concrete plane, tyre line y=985, display circle. |
| `placement_rules.json` | Per-class scale. Per-class width ranges are defined in placement_rules.json. |
| `vehicle_masks/` | Cached cut-out masks, written by the pipeline only. |

The compositing pipeline mirrors these values in
`supabase/functions/_shared/showroomTemplate.ts`. The edge runtime fetches the
approved CDN JPEG through the absolute URL mirrored in the pipeline. Frontend consumers share `src/lib/showroomBackground.ts`. The production pipeline renders directly at 1920×1082, matching the master pixels exactly. The background is never stretched or cropped. If a value changes, bump the matching version in both the server template and public frontend template.
Older composites then drop off the public site until Showroom is run again.
